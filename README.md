# Ukraine Live Camera Portal

Local portal for **Ukraine border queues** and **public traffic / border cameras**.

Ukrainian-side and Poland–Ukraine border webcams have been off since 24 February 2022. This app still shows:

- live truck/bus queues from the official eQueue service
- live Moldova Border Police cameras (HLS)
- official camera pages for Záhony and other neighbouring services
- a map of every monitored crossing

## Run it

```bash
npm install
npm start
```

Then open [http://localhost:4173](http://localhost:4173).
